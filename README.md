
# Componente Interactivo de Calificación

## Descripción
Este proyecto implementa un componente interactivo de calificación basado en el reto Interactive Rating Component de Frontend Mentor. Permite al usuario seleccionar una calificación del 1 al 5 y, al enviar, muestra un mensaje de agradecimiento con la calificación seleccionada.

## Herramientas utilizadas
- HTML5
- CSS3 (Flexbox)
- JavaScript para manipulación del DOM
- ChatGPT para asistencia en la optimización del código y solución de problemas

## Uso de ChatGPT
Durante el desarrollo, utilicé ChatGPT para:
- Escribir funciones para la selección y envío de calificaciones.
- Mejorar la legibilidad y organización del código.
- Resolver dudas específicas sobre manipulación del DOM y eventos en JavaScript.

## Instrucciones para usar el proyecto
1. Abrir el archivo `index.html` en cualquier navegador web moderno.
2. Seleccionar una calificación.
3. Hacer clic en el botón "Enviar".
4. Visualizar el mensaje de agradecimiento con la calificación seleccionada.
